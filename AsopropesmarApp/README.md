# AsopropesmarApp

Blazor Web App with OIDC Authentication against `https://auth.infor-business.com/`

## Configuration

In order to run the application, you must replace the placeholder ClientId and Secret in `appsettings.json` with actual values from IdentityServer.

1. Open `appsettings.json`
2. Set the correct `ClientId`
3. Set the correct `Secret`

Then you can run the application with `dotnet run`.
